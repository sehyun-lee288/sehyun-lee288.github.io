# Sehyun Lee — Personal Website

Static personal website for GitHub Pages.

## Files

- `index.html`: homepage.
- `cv.html`: printable curriculum vitae.
- `assets/css/`: shared and CV styles.
- `assets/images/portraits/`: homepage portrait.
- `assets/images/publications/`: publication thumbnails.
- `projects/gcc/`: self-contained GCC project website and its assets.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8000`
and visit `http://localhost:8000` on the same machine.

## Publish

Commit and push changes to the GitHub Pages publishing branch.
